# Fase 1: Discovery & Scoping
### 1 Semana
Entender cómo funciona el negocio de los food trucks, cómo se planean las rutas, cómo hacen pedidos los usuarios y cómo es el proceso de principio a fin desde que se ordena el producto hasta que el usuario lo recoge.

# Fase 2: Requirements and UX Design
### 1 Semana
Definición de requisitos e historias de usuario (con sus debidos criterios de aceptación), creación de mockups iniciales para tener una idea global de cómo será la aplicación visualmente y el flujo dentro de esta.
Se inicia diagramación con diagramas de clase y de arquitectura (preliminar).

# Fase 3: Development - Core Functions
### 2 Semanas
Se hace la planeación y desarrollo de las funcionalidades más importantes del proyecto: creación y visualización de órdenes y de rutas. Esto implica implementar todos los elementos de un CRUD.

# Fase 4: Development - Additional Features
### 2 Semanas
Se procede con la implementación de funcionalidades adicionales como estado de los pedidos y notas de inventario.

# Fase 5: Testing & Refinement
### 1 Semana
Se hacen pruebas de integración y end-to-end para validar la calidad del producto. Realizar pruebas con usuarios observando todo el flujo de principio a fin, donde se evidencie posibles errores y oportunidades de mejora. Recopilar feedback de los usuarios.

# Fase 5: Demo & Training
### 1 Semana
Presentar el demo de un MVP estable y completo, que cumpla con todas las funcionalidades solicitadas por el cliente. Después del visto bueno, proceder con el entrenamiento del staff que usará la aplicación.
